# Adversarial review

## Strongest objection

“Copy ALE” can become false precision if the report presents an inferred workflow distribution as an official one, or false privacy if it copies public tasks and calls them fresh.

## Required controls

- Label Figure 2 counts as official instance counts and Hamilton workflow quotas as project reconstruction.
- Require every one of the 1,490 delivered instances to pass final QC; do not inherit ALE's pending-QC status.
- Define structural replication as coverage, task anatomy, execution, evaluation and QC—not copying task content.
- Keep every client asset private while separating seen development material from unseen final material.
- Treat the 40 gap-fill slots as evidence-triggered customer extensions, not automatic rounding.
- Do not charge for supplier-caused defect replacement, rework, retries or regrades as new assets.
- Limit score claims to the frozen configured agent system and ALE-v2-matched coverage mix.

## Verdict

The revised product is procurement-ready at the specification level. Staffing, schedule, budget and throughput still require an instrumented pilot because ALE publishes no transferable production-capacity data.
