# Source 11 — METR task-completion time horizons

- **URL:** https://metr.org/time-horizons/
- **Surface:** Time Horizons 1.1 page; updated 2026-05-08
- **Role:** independent matched-human and repeated-run protocol evidence
- **Accessed:** 2026-08-09

> “provided with the same instructions and affordances as the AI agents”

## Supports

Human baselines should use people with matched skills actually completing tasks, with instructions and affordances stated explicitly. Success, time, subject qualification, task distribution, and attrition need separate reporting. The page also separates coherent multi-hour work from repeated independent short tasks.

## Limits

METR's distribution is concentrated in software, ML, and cybersecurity, and its low-context contractor framing is not a universal proxy for in-role practicing experts. Its times and run counts must not be copied into this project.

## Source assessment

Medium-high credibility for its transparent protocol; external validity is intentionally bounded.
