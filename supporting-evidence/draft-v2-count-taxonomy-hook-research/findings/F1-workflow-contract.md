# F1 — Use workflow package as the primary acceptance unit

## Finding

For this interview deliverable, define the base obligation as 1,000 final-accepted distinct workflow packages, each with at least one canonical runnable instance. Count extra variants, runs and repairs separately.

## Evidence chain

- The interviewer pairs “one question” with “one thousand questions,” which naturally tests workflow discovery and production leadership.
- ALE v2 separately reports 960 workflows and 1,490 instances.
- A workflow-first contract prevents low-cost variant inflation.

## Counterargument

The interview did not formally define the unit, and a 1,000-workflow program is materially heavier than a 1,000-instance program.

## Status

Project recommendation requiring written confirmation; not an ALE fact.
