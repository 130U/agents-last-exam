# Agents' Last Exam — 1,000-Task Delivery Research

本仓库整理 UniPat 面试任务中“如何领导生产 1,000 道 ALE 风格任务”的研究与交付材料。

## Repository map

- `core/` — 可直接进入最终文字报告、面试答辩或项目设计的核心材料。
- `supporting-evidence/` — 完整研究包、来源快照、QA/渲染产物、访谈与视频材料，以及辅助研究。
- `supporting-evidence/UPLOAD_MANIFEST.md` — 本地来源到 GitHub 路径的映射、打包说明与公开边界。

## Editorial principle

核心区强调决策密度；支持区保留可追溯证据和完整研究过程。原始本地文件未被移动、重命名或改写。
